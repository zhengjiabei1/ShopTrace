# 失败分类

30 个外部任务的结果是 12 通过、14 失败、4 未知。下面按轨迹归类，不按最终答案猜。

## 环境

站点不可用，或页面没有暴露任务需要的内容。

- Allrecipes 7、9、13：返回 access-issue 页面，不是菜谱；三次都以 blocked 结束，记为 unknown。
- Wolfram 5：输入页正常，但结果区域没有渲染；agent 以 blocked 结束，记为 unknown。
- ArXiv 6：一次尝试遇到 `Error 503 first byte timeout`，无法核对。

这类不计入模型失败，单独记为环境 unknown。

## 观测

页面能打开，但送给模型的观测过大，或丢失了关键信息。

- Cambridge 0 在压缩前：sustainability 词条页有 263 个可交互元素，观测达到 134,297 字符，第 3 步就超过 96k 预算。
- 压缩后：同一页面的模型输入降到 35,018 字符，4 步完成，并给出正确的 IPA 和释义。

这类问题出在模型输入，不是浏览器动作。

## 导航

页面能打开，但走了错误路径，或动作超出了允许范围。

- Apple 12 在加入 support 子域之前：点到了 `support.apple.com`，不在 allowed origin 内，连续三次被拒绝。
- Hugging Face 13：到了 Llama 文档，但没有进入 LlamaTokenizer 页面，随后开始滚动。

## 循环

Agent 重复同一动作，但没有进展。

- Hugging Face 13：在同一个 Llama 页面连续滚动 38 次。
- Wolfram 11：重复点击 Compute 并等待，跑到 50 步。
- ArXiv 10：重复点击同一个搜索控件，跑到 50 步。

加入目标身份检测后，Wolfram 在 22 步停止，ArXiv 在 16 步停止；仍然失败，但成本被限制住了。

## 预算

任务还在进行，但步数或时间预算耗尽。

- Apple 1：检查 iOS 17 兼容性时用完 50 步。
- Coursera 5：搜索 C++ Specialization 时用完 50 步。

预算停止是这次尝试的失败，不等于任务不可能完成。

## 协议

模型返回的动作不符合封闭工具协议，或不符合当前页面状态。

- ArXiv 11：连续三次无效动作，run 结束。
- Coursera 11：连续三次无效动作，run 结束。
- 过期元素引用属于普通无效动作；连续三次无效才会升级为协议停止。

## Provider 和基础设施

- 一次 DeepSeek 尝试返回 HTTP 402，原因是账户余额耗尽；这是 provider 失败，不是 agent 决策。
- 本地磁盘中断和取消的运行单独记录，不混进模型成功率。

## 怎么读这些数字

- 环境 unknown 不进入已知成功率，但计入覆盖率。
- 循环和预算停止算失败。
- 协议停止算失败，但原因是动作契约，不是答案本身。
- 不要拿 30 任务通过率和 WebVoyager 榜单直接比；任务集、评分方式和 origin 策略都不同。
